# SolidFreeCAD alpha.6 visual and workflow system

## Product direction

SolidFreeCAD should feel immediately understandable to an experienced mechanical-CAD user while retaining its own identity. The design goal is familiarity of workflow, not visual duplication of any proprietary product.

## Interface hierarchy

1. **CommandManager**: task tabs and grouped commands.
2. **FeatureManager**: model history and object selection.
3. **PropertyManager**: contextual operation controls with accept/cancel.
4. **Configurations**: foundation for dimensional variants.
5. **Heads-Up toolbar**: view and inspection commands separated from feature creation.
6. **Status bar**: engine, format and current model state.

## Workflow rule

The primary part workflow is:

`Pieza → Plano/Cara → Croquis → Relaciones/Cotas → Operación → Edición`

The UI may guide this sequence, but every production operation must delegate to a real FreeCAD command or produce a valid native BRep. Buttons with unavailable backends stay disabled.

## Visual rules

- compact neutral chrome;
- one restrained blue accent for selected tabs and guidance;
- green accept and red cancel controls;
- yellow contextual workflow messages;
- large icons for primary actions, smaller icons for secondary actions;
- original SVG resources only;
- no copied third-party CAD artwork or logos;
- classic FreeCAD remains available as compatibility mode.

## Alpha.6 acceptance checks

- seven task tabs are present;
- model, properties and configurations tabs are present;
- accept/cancel controls are visible;
- FeatureManager tree exists;
- Heads-Up toolbar exists;
- unavailable sheet-metal/assembly commands are disabled;
- interface screenshot is generated by the Windows workflow;
- the parametric demo part saves, reopens and exports to STEP.

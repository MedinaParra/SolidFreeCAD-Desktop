# 0.1.0-alpha.12 — native standalone part modelling

- Replaced static BRep extrusion with editable native Part Design features.
- Added Pocket, Revolution, Fillet and Chamfer with live preview transactions.
- Added arbitrary reference planes, planar-face sketch support, line drawing,
  transient previews and editable native dimensions.
- Replaced placeholder commands with a working CommandManager, action search,
  tree filtering and contextual PropertyManager.
- Added real FreeCAD runtime regressions, visual evidence and Windows packaging.
- Kept Ubuntu and the previous overlay unchanged.

# Changelog

## 0.1.0-alpha.7

- Replaced the visibly layered alpha.6 desktop with one coherent professional Windows shell.
- Added a clean quick-access strip with file actions and command search.
- Hid native FreeCAD toolbars while the SolidFreeCAD workbench is active.
- Restyled the full-width tabbed CommandManager and added a weldments foundation tab.
- Added a compact left design manager with Model, Properties and Configurations.
- Moved native task compatibility to the left-side Combo View tab group.
- Added a neutral light modelling background and persistent SolidFreeCAD alpha.7 branding.
- Removed the duplicate Archivo menu created by the earlier workbench initialization.
- Preserved FreeCAD 1.1.1, OpenCASCADE BRep geometry, FCStd documents and original SolidFreeCAD icon resources.

## 0.1.0-alpha.6

- Added integrated FeatureManager, PropertyManager and configurations tabs.
- Added compact Heads-Up view toolbar.
- Extended CommandManager with sheet-metal and assembly foundations.
- Added parametric demonstration plate with through-hole and pocket.
- Added end-to-end BRep, parameter edit, FCStd save/reopen and STEP export test.
- Added automated Windows interface screenshot artifact.
- Added application-mother metadata schema and example.
- Preserved the native FreeCAD engine, FCStd format and classic compatibility path.
- Continued using original SolidFreeCAD icon resources only.

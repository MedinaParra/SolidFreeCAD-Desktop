# SolidFreeCAD for Windows

Windows x64 is the current delivery priority.

## Initial target

The first distributable Windows version should provide:

- a branded SolidFreeCAD application shell;
- the official FreeCAD document and geometry engine;
- FCStd open/save support;
- STEP/STP import;
- a basic mechanical-design ribbon;
- document tree, property panel and 3D viewer;
- New, Open, Save, Undo, Redo, Fit All and Isometric commands;
- classic FreeCAD mode as a compatibility fallback;
- a portable ZIP generated by GitHub Actions.

## Build stages

### Stage 1 — Baseline

Compile the pinned, unmodified FreeCAD source on a GitHub-hosted Windows x64 runner. This proves the toolchain before SolidFreeCAD code is introduced.

### Stage 2 — Overlay

Apply the shared SolidFreeCAD GUI overlay and verify that the classic FreeCAD interface can still be started.

### Stage 3 — Packaging

Collect runtime dependencies and publish a portable ZIP artifact. Add an installer only after the portable artifact launches reliably.

### Stage 4 — Validation

Add smoke tests for application startup, opening a small FCStd file, importing a STEP file and executing a basic macro.

## Platform-specific files

Windows manifests, `.ico` resources, installer definitions and dependency bootstrap logic belong in this directory or `scripts/windows/`. Shared GUI and CAD behavior must remain outside this directory.
